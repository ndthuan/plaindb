# Security

## Supported versions

Only the newest release gets fixes: a fix ships as a new release, not as
a patch to an older one.

## Reporting a vulnerability

Report it privately, through GitHub's private vulnerability reporting:
the repository's **Security** tab, then **Report a vulnerability**.
Please do not open a public issue, pull request or discussion about it.

Say in the report:

- the version and the operating system;
- what an attacker needs to start with and what they get;
- the steps to reproduce it, as small as you can make them, and what you
  saw;
- whether it is known elsewhere, and if you plan to publish it, when.

plaindb has one maintainer, so the times here are aims, not promises: an
answer within a week saying whether it is taken as a vulnerability, and
for one that is, a fix released as soon as one is ready, with the report
credited unless you would rather not be named.
